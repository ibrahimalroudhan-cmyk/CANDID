# Contributing

CANDID is research software published under an all-rights-reserved notice (see
[LICENSE](LICENSE)). Code contributions are not being accepted at the moment.

What is welcome:

- Questions and bug reports about the published code, as issues.
- Collaboration, validation or research-access enquiries: email
  [Ibrahim@candidlabs.org](mailto:Ibrahim@candidlabs.org).

Please never include patient data, scans or identifiable information in an
issue. CANDID is research software and not a medical device.
